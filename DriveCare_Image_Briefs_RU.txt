DRIVECARE — ИЗОБРАЖЕНИЯ ДЛЯ ЭКРАНОВ И ОНБОРДИНГА

В приложении уже подключены места для всех изображений и отдельные векторные
иллюстрации по умолчанию. Ниже — задания для финальных иллюстраций, которые
можно заказать дизайнеру или использовать как промпты генератору изображений.
Все 17 растровых иллюстраций сгенерированы и добавлены 25.10.2026.
Готовые WebP: app/src/main/assets/artwork/.
PNG-оригиналы, промпты, манифест и обзор светлой/тёмной темы:
design/artwork/. Исходные задания ниже сохранены для дальнейших правок.

КАК ДОБАВИТЬ
1. Экспортировать каждую иллюстрацию в WebP (sRGB). Имена файлов ниже точные,
   строчными латинскими буквами, без пробелов.
2. Поместить файлы в app/src/main/assets/artwork/ текущего репозитория.
3. Пересобрать приложение. Менять Kotlin-код или ресурсы не нужно.
   Пока файл отсутствует, видна соответствующая векторная иллюстрация.
4. Для шапок: 1600 x 640 px (5:2); для онбординга: 1600 x 1000 px (8:5).
   Рекомендуемый вес каждого файла до 250–400 КБ. Альфа-канал приветствуется.
   Приложение вписывает изображение целиком, без обрезки, в скруглённый контейнер.

ОБЩИЙ СТИЛЬ ВСЕГО КОМПЛЕКТА
Спокойная современная автомобильная иллюстрация: мягкие объёмы, простой силуэт,
матовые материалы, чистый контур, минимум деталей. Один узнаваемый синий
компактный автомобиль без марки и логотипа на всех изображениях. Палитра:
синий #4B7BEC, светлый голубой #BDD8FF, мягкая бирюза #6ECFC4,
тёмный графит #25324B; небольшие тёплые акценты. Основная композиция по центру,
вокруг неё свободные 12% поля. Предметы хорошо читаются на маленьком экране.
Прозрачный фон позволит использовать тему приложения в светлом и тёмном режиме.
Не рисовать текст, цифры, логотипы, госномера, водяные знаки, кнопки или интерфейс.
Не изображать повреждения, аварии, чрезмерный глянец или рекламный суперкар.

Базовый английский префикс для каждого промпта:
"Create a cohesive premium mobile-app illustration for DriveCare. Soft sculpted
shapes, matte surfaces, restrained blue and teal palette, graphite details, calm
friendly mood. Use the same generic compact blue hatchback, with no brand marks.
Transparent background, centered composition, generous safe margins, legible at
small size. No text, numbers, logos, license plates, watermarks or UI controls."
Добавьте к нему описание конкретной сцены ниже и нужное соотношение сторон.
